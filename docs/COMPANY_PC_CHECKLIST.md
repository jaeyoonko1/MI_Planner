# 회사 PC 시험 설치 체크리스트

> 대상: 회사 Windows PC(보안망, 외부 인터넷 불가). 집에서는 가짜 데이터로만 확인했고, 아래는 **회사에서만 확인할 수 있는 것**이다.
> 회사 데이터는 집으로 가져오지 않는다 (D-17). 이 문서의 결과도 "통과/실패"만 적어 가져온다.

## 1. 반입 준비 (집에서)

- [ ] 저장소 폴더 전체(`.venv` 제외, `vault/`·`data/`·`config/local.json` 제외)를 반입 매체에 복사
- [ ] Python 3.11 이상 설치 파일(회사에 없을 때만) — 3.12로 개발했으므로 3.11 이상이면 된다
- [ ] 의존성 wheel 모음 만들기: `pip download -r requirements.txt -d wheels` (집에서, 윈도우 64비트 / 같은 Python 마이너 버전)
  - `fastapi`, `uvicorn`과 그 하위 의존성(pydantic, starlette, anyio, h11, click 등)이 모두 들어 있어야 한다
  - 컴파일이 필요한 패키지가 섞여 있지 않은지 확인: 파일 이름이 모두 `-py3-none-any.whl` 이거나 `win_amd64` 바이너리 wheel 이어야 한다
  - `pydantic-core`는 `win_amd64` 바이너리 wheel이다. Python 마이너 버전이 다르면 받은 wheel이 맞지 않는다 — 회사 Python 버전을 먼저 확인
- [ ] 개발용(`requirements-dev.txt`: pytest 등)은 회사에서 테스트를 돌릴 때만 필요

## 2. 설치 (회사 PC, 오프라인)

1. 폴더를 `C:\MI_Planner` 같은 짧은 경로에 둔다 (한글·공백이 없는 경로 권장, 있어도 동작해야 하므로 시험 항목에 포함)
2. 터미널에서 가상환경 만들기
   ```
   py -3 -m venv .venv
   .venv\Scripts\pip install --no-index --find-links wheels -r requirements.txt
   ```
   - `--no-index`가 오류 없이 끝나면 오프라인 설치 성공. 사내 프록시 pip를 쓸 수 있으면 `--proxy`로 대체 가능
3. `run.bat` 더블클릭 → 검은 창에 `Uvicorn running on http://127.0.0.1:8765` 표시, 브라우저 자동 열림
4. 첫 실행 후 `data\mi_planner.db`, `vault\`가 생겼는지 확인 (마이그레이션 001~005 자동 적용)
5. 종료는 검은 창에서 Ctrl+C. 같은 포트가 이미 쓰이면 `run.bat`이 오류를 낸다 — 포트 충돌 시 다른 프로그램을 먼저 닫는다

## 3. 브라우저별 확인 (Edge 기본, Chrome·웨일 선택)

각 항목을 **Edge → Whale** 순서로 확인한다 (D-16).

### 3.1 기본 동작

- [ ] 첫 화면이 오늘 화면으로 열리고 사이드바에 여섯 최상위(일지/MI 공정업무/연구 개발/성과/업무 매뉴얼/스터디)가 보인다
- [ ] 개발자도구(F12) → 네트워크 탭에서 `127.0.0.1:8765` 외 요청이 **0건** (외부 요청·차단 경고 없음)
- [ ] 콘솔에 빨간 오류가 없다
- [ ] 한글 입력(IME)으로 일지 줄 입력·할일 제목 수정이 끊기지 않는다 (조합 중 Enter/Tab이 확정을 방해하지 않는지)

### 3.2 키보드 (브라우저가 가로채는지)

| 키 | 기대 동작 | 가로채이면 대안 |
|---|---|---|
| Ctrl+1 | 줄 표시 순환 (☐ ☑ ★ !) | Alt+1, Ctrl+Alt+1 |
| Ctrl+N | 할일 페이지 추가 | Alt+N |
| Ctrl+Alt+H | 형광펜 | Alt+Shift+H |
| `[` | 사이드바 접기 | 버튼 |
| Shift+Enter (할일 제목) | 이슈 상세 패널 | 제목 더블클릭 |
| Tab / Shift+Tab (일지 줄) | 들여쓰기·내어쓰기 (포커스 유지) | — |

- [ ] 일지 도움말의 "키 확인" 패널에서 위 키가 앱까지 오는지 확인하고, 안 오는 키는 결과를 DECISIONS에 기록
- [ ] 웨일은 사이드바·확장 단축키와 겹치는 키가 있는지 별도로 확인

### 3.3 화면 크기·테마·밀도

- [ ] 사내 모니터 해상도에서 1024px / 1280px 폭으로 창 크기를 바꿔 가로 스크롤·잘림이 없다
- [ ] 브라우저 확대 100%·125%(윈도우 배율 125%가 흔함)에서도 사이드바·표가 겹치지 않는다
- [ ] 테마 시스템/라이트/다크, 밀도 컴팩트/기본/여유 전환 후 새로고침해도 유지된다
- [ ] 윈도우 다크/라이트 전환 시 "시스템" 테마가 따라간다

### 3.4 마우스 전용 동작 (집에서는 합성 이벤트로만 확인함)

- [ ] 사이드바 트리에서 페이지 끌어 하위로 이동·순서 변경
- [ ] 구조 화면: 계층 칩 끌기, 그룹 끌어 이동(가운데=하위, 가장자리=앞), 순환 이동이 거부되는지
- [ ] 주간·월간: 할일 행·손잡이(⠿)를 날짜 칸으로 끌기, "되돌리기" 토스트
- [ ] 이미지: 실제 스크린샷 Ctrl+V 붙여넣기, 모서리 핸들 끌어 크기 변경, 크기 바의 칩
- [ ] 모달 창(계층 편집·분류 관리 확인·페이지 생성): Esc로 닫으면 누르기 전 버튼으로 포커스가 돌아온다

## 4. 데이터 흐름 손시험 (가짜 데이터로 먼저, 이후 실제 업무로)

1. 오늘 화면 일지에 `- [ ] EQ-A01 점검 (LOT-TEST-001)` 입력 → 체크 줄 승격 → 할일 목록·주간·월간에 같은 ID로 보임
2. 구조 화면에서 분류 값 변경·자유 배치 이동·복사(새 ID) 후 새로고침해도 유지
3. 이슈를 "페이지로 확장" → 두 번 눌러도 페이지가 하나만 생김, 상세 메모와 페이지 본문이 같은 글
4. 메모에 이미지를 붙이고 폭 변경 → **앱 종료(Ctrl+C) 후 `run.bat` 재실행** → 그대로 남아 있음
5. 페이지 위치 규칙 탭에서 규칙을 고치고 저장하지 않은 채 다른 화면으로 이동 → 확인 창이 뜬다
6. 기존에 쓰던 `data\mi_planner.db`가 있다면 **백업 후** 새 버전으로 실행 → 마이그레이션 오류 없이 기존 할일이 보인다 (백업 파일은 `data\`에 날짜를 붙여 복사)
7. `vault\` 폴더를 탐색기에서 열어 `index.md`가 메모장으로 그대로 읽히는지 확인 (D-03 일반 파일 원칙)

## 5. 파일·보안 환경 점검

- [ ] 백신·DLP가 `vault\`, `data\` 쓰기를 막거나 실행을 지연시키지 않는다 (저장 상태가 "저장 실패"로 바뀌지 않는지)
- [ ] 회사 프록시·방화벽이 `127.0.0.1:8765` 로컬 접속을 막지 않는다 (막히면 포트를 바꿔 `run.bat`의 `--port` 수정)
- [ ] 경로 길이: 한글이 많은 페이지 제목으로 3단계 이상 중첩해도 저장된다 (Windows 260자 제한)
- [ ] 휴지통: 페이지 삭제 후 `vault\.trash\`에 폴더가 생긴다 (바로 지워지지 않음)
- [ ] 폴더를 OneDrive/네트워크 드라이브에 두지 않는다 (잠금·동기화 충돌 방지). 로컬 디스크에 둔다

## 6. 집에서 확인하지 못한 것 (회사에서 결과를 기록)

- 실제 Edge/Whale 일반 탭에서의 단축키 가로채기, 실제 클립보드 이미지 붙여넣기, 실제 마우스 끌어 놓기 (집에서는 합성 이벤트·미리보기 브라우저로만 확인)
- 100%가 아닌 윈도우 배율·실제 모니터 해상도에서의 레이아웃
- 회사 Python 버전·wheel 호환, 오프라인 `pip install`
- 백신·DLP·프록시 영향, 장시간(하루 이상) 켜 두었을 때 메모리·DB 잠김
- 실제 한글 IME 조합 중 일지 줄 편집기·메모 편집기의 동작
- 실제 데이터 양(수천 건 할일, 큰 이미지)에서의 속도
- 스크린리더(Narrator)로 읽기 — 집에서는 aria 속성·이름 유무만 점검

## 7. 결과 기록

문제를 찾으면 회사에서는 증상과 재현 순서만 적고(회사 데이터 제외), 집에서 가짜 데이터로 재현해 고친다.
시험 일정(1주일 실사용)은 flow의 P2-07과 이어진다.
