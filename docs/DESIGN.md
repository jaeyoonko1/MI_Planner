# MI Planner UI·UX 설계 — Final

2026-11-24 · P2B-01 설계 확정. 인터랙션 기준은 [Final 프로토타입](../web/design/prototype_final.html)이다. 프로토타입은 가짜 데이터로 동작하는 오프라인 단일 HTML이며 상태는 탭 수명 동안 유지된다. 아래의 영구 저장·마이그레이션·복구는 본 앱 구현의 인수 조건이다.

## 오늘과 업무 구조

앱의 일상 진입점은 오늘이다. 데스크톱 첫 화면에 **납기 우선 목록과 오늘 일지**를 나란히 둔다. 목록에 마우스를 올리거나 포커스를 주면 메모를 읽고, 제목은 한 번 클릭해 수정하고 더블클릭으로 상세 패널을 연다. 추적할 대상이 많을 때는 구조 화면을 연다. Final 시안은 오늘 화면으로 시작한다.

구조 화면은 한 행에 계층 이름, 상태 또는 완료 수, 제품, 요청자, 납기를 담는다. 그룹 완료 수는 그 아래 고유 이슈 중 완료된 수 / 전체 수다. 전체 접기·펼치기와 개별 접기를 제공한다. 이슈 ID는 정렬·분류·이동 후에도 유지한다.

## 이슈와 페이지

- **이슈 추가**는 할일 레코드만 만든다. 제목·상태·납기·요청자·메모와 분류값만으로 일지와 구조 표에서 업무를 끝낼 수 있다.
- **페이지로 확장**은 기존 이슈에 페이지 한 개를 연결한다. 같은 이슈 ID·메모·일지 연결을 보존하며, 두 번째 실행은 기존 페이지를 연다. 처음부터 페이지가 필요하면 별도의 **할일 페이지 추가**를 사용한다.
- 새 페이지 위치는 첫 일치 AND 규칙 → 기본 경로 순으로 결정한다. 생성 전에 경로를 확인하고 일지 아래 또는 지정 폴더로 바꿀 수 있다. 예: 유형=셋업 AND 제품=HBM → MI 공정업무/셋업/[제품]. 이후 분류를 바꿔도 이미 배치한 파일은 자동 이동하지 않는다.
- 체크 줄 승격은 할일 ID를 한 번 연결한다. 오늘·월간 일지·할일·구조 표에서 같은 ID의 제목·완료 상태를 읽는다. 자유 기록과 계획일·납기 참조를 구별하고, 같은 날짜에는 동일 이슈를 중복 집계하지 않는다.

## 계층 편집

초기 보기는 **이슈 계층**이다(V-011, D-48): 에픽 같은 상위 수준도 이슈이며 헤더 행은 그 이슈의 제목 + 수준 배지, 계층은 상위 이슈 연결이다. 히어로의 **이슈 추가**(시안과 같은 주 버튼)로 어느 수준이든 만들고(선택한 이슈 아래가 기본, '계속 추가'), 이슈 계층의 '계층 편집'은 수준 이름·모양·색·순서를 바꾼다. 분류 기준 보기(**에픽 → 유형 → 이슈** 분류 값 묶음)와 자유 배치는 모드 칩으로 고른다. 분류 기준에서 규칙이 깨지면 자유모드로 전환된다. 자유모드에서는 계층 하이어아키가 무시된다.  V-014(D-49)에서 이슈도 편집 가능한 실제 수준이 됐다. 자식의 수준 순위가 상위보다 높으면 구조 표에 ⤴ 역순을 함께 표시한다. 에픽은 보라색 겹층, 유형은 민트색 격자, 제품은 파란 상자, 이슈는 마름모와 이슈 번호로 구분한다. 색을 구별하기 어려워도 모양과 이름으로 판별할 수 있어야 한다.

전용 편집 창에서 기존 분류 추가, 사용자 정의 분류 생성, 보기에서 단계 제외, 드래그 또는 위·아래 버튼으로 순서 변경, 아이콘·색 선택을 제공한다. **적용** 시 한 번에 반영하고 **취소** 시 원래 보기를 유지한다. 보기에서 단계를 빼도 이슈의 필드값은 보존한다. 정의·선택지 자체의 삭제는 분류 관리에서 영향 범위와 규칙 참조를 확인한다. 분류 기준 보기의 이슈 행은 분류값 묶음 아래에 표시된다.

분류 보기에서 단계 핸들을 옮기면 전체 관점이 바뀌고, 이슈를 그룹으로 옮기면 해당 이슈의 필드값이 바뀐다. 자유 배치에서는 그룹을 하위 이슈와 함께 옮기며 순환을 거부한다. 페이지 트리 가운데에 놓으면 자식으로 이동하고 위·아래 가장자리는 형제 순서를 바꾼다. 두 트리는 서로 다른 위치 정보를 관리한다.

복사한 이슈에는 새 ID를 부여한다. 분류 보기의 에픽 복사는 다른 유형 가지에 걸친 같은 에픽의 이슈까지 포함한다. 자유 배치에서 그룹 복사는 선택한 하위 트리를 대상으로 한다. 원본의 상태·메모가 복사본 편집으로 바뀌지 않아야 한다.

V-014에서 세 보기의 **이슈 추가**는 같은 시트를 사용한다. 기본 수준이 먼저 선택되며 이슈 계층에서 명시적으로 하위 추가를 선택하면 부모 바로 아래 수준을 제안한다. 수준 칩의 우클릭이나 Shift+F10으로 이름·순서·기본 수준·삭제를 관리한다. 분류 기준에서는 가져올 분류 값을 확인하고 개별적으로 뺄 수 있다. 자유 배치에서는 그룹 안에 넣거나 행 바로 위·아래를 지정할 수 있다. Ctrl+Enter는 같은 위치, Shift+Enter는 이슈 계층의 하위 또는 해당 보기의 그룹 안에 추가한다. 줄 단축키 설정이 꺼져도 버튼과 우클릭 메뉴를 사용할 수 있다.

구조의 세 보기에서 행을 한 번 클릭하면 오른쪽 상세창이 열린다. 방향키로 행을 옮기면 120ms 뒤 상세가 따라오며, Enter는 제목 편집에 포커스를 준다. Esc는 구조 행으로 돌아가고 구조에서 한 번 더 누르면 창이 닫힌다. Shift·Ctrl로 여러 행을 고르면 선택 개수를 표시한다. 접기 화살표는 가지 상태만 바꾼다.

이슈 번호 옆 수준 버튼을 눌러 공용 수준 칩을 펼친다. 상세는 상위 경로와 직접 하위를 탐색하고 하위를 추가할 수 있다. 수준·상위는 즉시 저장하며 구조 탭의 Ctrl+Z·Ctrl+Shift+Z로 되돌리거나 다시 적용한다. 상하위 순위가 뒤집히면 ⤴ 안내를 붙인다. 분류 값과 자유 배치 그룹은 이름·이슈 수·허용된 작업을 카드로 표시한다. 상세창은 1280px 이상에서 구조 표와 나란히 배치되고 1024px에서는 표 위에 열린다.

## 입력과 시각 규칙

- 할일은 한 줄로 입력하며 상세 모드에서 납기·요청자·제품·유형·에픽·태그·사용자 정의 필드를 선택한다. 마지막으로 확정한 값을 다음 입력의 기본값으로 사용한다.
- 월간 일지는 열=주차, 행=요일이다. 오늘 강조, 주말 접기, 날짜별 계획·납기·연결 이슈와 본문 편집을 제공한다.
- 본문 편집 중 Tab/Shift+Tab은 선택한 줄 전체를 한 단계 들여쓰기/내어쓰기하고 편집 포커스를 유지한다. Ctrl+. 불릿, Enter 목록 연속 입력, 제목·문자 서식, 하위 줄 접기를 지원한다. Ctrl+1 표시 순환은 D-21을 따른다. Ctrl+N은 할일 페이지 추가이며 브라우저가 선점하면 Alt+N/버튼을 사용한다.
- 오늘·주간·월간 줄 편집은 수준(들여쓰기)이 달라도 불릿 모양·크기·색·정렬이 같다(고정 폭 마커 칸, 수준은 들여쓰기와 얇은 안내선으로만 구분, ☐ ☑ ★ !는 별도 표시). 노트와 같은 줄 안 서식(굵게·기울임·밑줄·취소선·글자 크기·글자색·형광펜·서식 지우기)을 토글 칩 도구줄(오늘·확대 창)과 칸 아래 작은 띠(월간·주간, 편집 중에만)로 제공하고 같은 단축키·켬/끔 스위치·우클릭 메뉴를 쓴다. 선택이 없으면 줄 전체에 적용한다(D-47).
- 붙여넣은 이미지는 비율을 유지해 본문 폭 안에 표시한다. 호버·포커스에서 자동, 소형, 고정 너비를 선택한다.
- 노트와 독립 이슈 메모의 Excel 표는 드래그·Shift+클릭·Shift+방향키로 범위를 잡는다. 포커스가 있는 표 안에 선택 범위 테두리를 표시하고, Esc로 활성 셀 하나만 선택한다. 병합 셀은 일부에 닿아도 전체를 포함한다. 셀 선택 상태에서 Ctrl+C로 복사하고 Ctrl+D/R로 첫 행·열의 값을 아래·오른쪽에 채운다. 병합 모양이 다른 범위에 채우려 하면 원래 선택과 내용을 유지하고 안내를 띄운다.
- Excel 셀 오른쪽 경계를 끌면 기준선이 열의 새 너비를 표시한다. 포인터를 놓으면 너비가 저장된다. 가로 병합에서 보이는 오른쪽 경계는 병합의 마지막 열을 조절한다. 한 번의 Ctrl+Z/Y로 이전 너비와 선택 범위를 복원하거나 변경을 다시 적용한다.
- Excel 셀의 우클릭 메뉴(Shift+F10으로도 열기)에서 **열 너비 자동 맞춤**을 쓰면 선택된 열의 전체 행을 기준으로 너비를 맞춘다. 선택 범위 안을 우클릭하면 현재 범위를 유지한다. 자동 맞춤 한 번을 Ctrl+Z/Y로 되돌리거나 다시 적용한다.
- Excel 셀 선택 상태에서 Ctrl+X로 잘라내면 클립보드에 선택을 담은 직후 원본의 내용이 비워진다. 선택 범위는 유지하고 Ctrl+Z/Y로 복구하거나 다시 비운다. F2로 셀의 텍스트를 편집하는 동안에는 브라우저의 텍스트 잘라내기를 쓴다.
- 다크 시안의 기준색은 바탕 #02040a, 패널 #111a2a, 본문 #edf4ff, 행동 블루 #729eff다. 블루는 선택, 시안은 강조, 적색은 납기 지남을 뜻하며 항상 문자 또는 모양을 함께 쓴다. 구조 표 행은 기본 28px, 컴팩트 23px. 설정에서 밀도와 단축키를 독립적으로 바꾼다.
- 본 앱은 D-23의 시스템·라이트·다크, D-24의 여섯 최상위 트리, 로컬 폰트와 인라인 SVG를 유지한다. 빈 결과·저장 실패·재시도·되돌리기와 키보드 포커스를 설계에 포함한다.

## 구현 인수 기준

기존 할일 필터·일지 파일·페이지 링크는 마이그레이션 후에도 작동해야 한다. 구조 보기 설정(필드 ID 순서·아이콘·색·자유 배치 부모와 순서)과 실제 페이지 ID/위치는 별도로 저장한다. 페이지 확장이나 이동 실패는 이슈 중복·고아 링크를 남기지 않아야 한다. 재시작 후 보기 및 연결 복원, 1024/1280px, 테마·밀도, 단축키 켬/끔, 오프라인 실행을 확인한다. 단계별 범위와 완료 상태는 [Project Flow](../project_flow.html)의 P2B가 기준이다.

## 일지를 쓰고 업무를 추적하는 흐름

오늘을 열면 왼쪽 일지의 원하는 줄을 한 번 클릭해 그 자리에서 쓴다. 오른쪽에는 **납기 임박 / ★ ! 중요 / 오늘 일지**가 있다. 납기 탭은 연체부터 3일 이내까지, 중요 탭은 별표·긴급 중 미완료만 보여 준다. 할일 제목도 한 번 클릭해 고친다. Enter로 확정하고 Escape로 제목 수정을 취소한다. 체크 버튼은 즉시 완료를 전환한다.

| 대상 | 한 번 클릭 | 더블클릭 |
| --- | --- | --- |
| 오늘·주간·월간의 일반 일지 줄 | 커서 위치에서 편집 | 오른쪽에 해당 날짜 전체를 확대해 편집 |
| 할일과 연결된 일지 줄 | 그 줄의 텍스트 편집 | 오른쪽에 같은 이슈의 제목·속성·메모 열기 |
| 할일 목록의 이슈 제목 | 제목 직접 수정 | 오른쪽 이슈 상세 열기 |
| 구조 표의 행 | 선택하고 오른쪽 상세 열기 · 선택된 이슈 제목을 다시 누르면 직접 수정 | — |
| 계층의 접기 화살표 | 하위 묶음 접기·펼치기 | — |
| 일지의 하위 줄이 있는 문단 | 왼쪽 접기 화살표로 하위 줄 숨기기 | 본문에서는 확대 우선. 별도 노트 편집기에서는 하위 줄 접기 |

확대와 페이지 생성은 별도 행동이다. 확대 창의 닫기·Esc는 편집을 반영하고 원래 화면으로 돌아간다. 할일 제목·상태·메모의 기준은 이슈 ID, 날짜 본문의 기준은 날짜다. 한쪽을 고친 직후 다른 화면이나 확대 창에서 이전 값이 돌아오면 실패다.

### 공통 줄 편집기

- 일반 문장, 불릿, 태그가 달린 할일, 제목 1~3, 들여쓴 하위 줄, 이미지가 한 문서 안에 함께 들어간다. 선택 범위가 여러 줄이면 들여쓰기·불릿·표시 변경을 선택한 줄에 적용한다.
- Tab / Shift+Tab으로 들여쓰기·내어쓰기한다. 편집 중 Tab은 단축키 설정과 관계없이 편집기 안에 머문다. 새 줄은 깊이·불릿을 이어받고 할일 ID·표시·접힘은 새로 시작한다. 빈 불릿에서 Enter는 한 단계 내어쓴 뒤 불릿을 해제한다. 줄 시작 Backspace는 표시·제목·불릿·깊이를 차례로 해제한다.
- Ctrl+.는 불릿을 전환한다. Ctrl+1 또는 Alt+1은 일반 → ☐ → ☑ → ★ → ! → 일반 순환, Ctrl+Enter는 완료 전환이다. 별표와 긴급도 할일이다. 긴급은 높은 우선순위를 부여한다. 표시·계획일을 해제해도 기존 이슈를 보존한다. 하위에 들여쓴 할일은 부모 ID로 연결한다.
- Alt+↑/↓는 하위 줄을 포함한 블록을 이동한다. Ctrl+Alt+1/2/3은 제목, Ctrl+Alt+0은 본문이다. 자식 수와 접힘 상태를 표시하고 펼치면 원래 순서가 복원된다.
- 선택한 텍스트에 Ctrl+Alt+H로 형광펜, Ctrl+-로 취소선, Ctrl+Shift+N으로 서식 지우기를 적용한다. 굵게·기울임·밑줄과 인라인 코드도 본문 왕복 시 보존한다. Alt+Shift+D/T는 날짜·시간 입력이다.
- 여러 줄 텍스트를 붙이면 줄·목록·들여쓰기를 복원하고 원본 이슈 ID는 복제하지 않는다. 이미지 붙여넣기는 종횡비를 보존하는 자동 폭으로 시작한다. 이미지 위에서 자동 / 240 / 480 / 720px / 원본 또는 직접 입력한 픽셀 폭을 고른다. 핸들 드래그로 크기를 바꾸고 원본 해상도를 확인할 수 있다.
- 줄을 할일로 승격할 때 `@사람`, `~오늘`·`~내일`·`~월/일`, `!`, `제품:HBM`, `에픽:이름`을 속성으로 분리한다. 선택지 추가나 알 수 없는 항목은 피드백으로 표시한다. 표시 줄을 지우면 그날의 계획 연결을 해제하고 할일은 목록에 남긴다.

### 주간·월간 배치

주간은 월요일부터 일요일까지 날짜별 공통 편집기를 세로로 배치한다. 이번 주·이전 주·다음 주와 주말 표시 토글을 둔다. 옆에는 **계획 / 납기 / 날짜 없음** 목록을 둔다. 계획일과 납기는 독립적이다. 오늘·주간·월간은 같은 날짜의 본문, 이미지, 표시, 할일 ID를 읽는다. 주말을 숨기는 동작은 화면에만 적용한다.

월간은 열이 주차, 행이 요일인 표다. 월 경계·오늘을 표시하고, 주말과 날짜 없는 할일 트레이를 접을 수 있다. 주간·월간에서 할일을 날짜 칸에 놓으면 계획일을 바꾸고 원래 칸의 연결 줄을 옮긴다. 이미 배치한 줄은 호버 시 표시되는 손잡이로 옮긴다. 자유 기록과 납기는 그대로 유지한다. 드롭 직후 되돌리기는 원래 날짜를 복원한다.

### 목록·페이지·탐색

- 할일 목록은 검색·상태·필드 필터와 완료 표시를 지원한다. 목록·연결 줄 호버에서 본문 메모를 미리 본다. 상세에서는 제목, 속성 칩, 위치, 본문을 편집한다. 에픽 페이지에는 설명, 진행률, 하위 할일 목록과 에픽이 기본 선택된 추가 입력을 둔다.
- 빠른 추가의 상세 토글, 필드별 선택 버튼, 마지막 선택 기억 토글, 기본값 비우기를 제공한다. 페이지 추가 메뉴에서 할일 페이지·에픽·일반 노트를 선택한다. 파일 트리와 이슈 트리의 드롭 위치를 표시하고 순환 이동을 막는다.
- 분류 편집은 단일·복수 선택, 사람, 날짜, 숫자, 텍스트, 체크 필드와 선택지 계층을 지원한다. 목록 노출·필터 노출은 별도 설정이다. 위치 규칙은 조건·경로 템플릿·우선순위와 기본 위치를 관리하고 수동 고정을 지원한다.
- 앱 단축키와 편집기 단축키는 따로 설정한다. 앱에서 N은 빠른 추가, Ctrl+N / Alt+N은 할일 페이지, / 또는 Ctrl+K는 페이지·이슈·명령 검색, J/K는 목록 이동, X는 완료, Enter / Shift+Enter는 상세 / 페이지다. Ctrl+Shift+D는 상세 입력, Ctrl+Shift+.는 밀도, [는 사이드바, ?는 단축키 도움말이다. 텍스트 입력 중 단일 문자 단축키가 타이핑을 가로채지 않아야 한다.
- 시스템·라이트·다크, 컴팩트·기본·여유 밀도를 지원한다. 개인 설정과 업무 데이터는 별도로 취급한다. 프로토타입의 업무 데이터는 탭 안에서만 유지한다. 실제 저장, 실패 복구, 재시작 후 복원은 후속 구현에서 검증한다. 설비 평가 현황판은 별도 P4 범위다.

### 통합 인수 시나리오

1. 오늘에 형광펜 문장과 들여쓴 별표 할일을 입력한다. 주간과 월간의 같은 날짜에서 서식, 계층, ID를 대조한다.
2. 주간에서 다른 날짜로 옮기고 월간에서 새 위치를 확인한다. 되돌린 뒤 원래 날짜와 서식, 변경되지 않은 납기를 확인한다.
3. 목록에서 한 번 클릭해 제목을 고친 뒤 더블클릭으로 오른쪽을 열어 메모를 편집한다. 다시 열었을 때 같은 이슈이며, 명시적으로 확장하기 전에는 페이지가 없어야 한다.
4. 구조에서 유형을 에픽 위로 올리고 그룹을 복사한다. 원본 이슈의 일지와 복제 이슈의 메모가 독립적인지 확인한다.
