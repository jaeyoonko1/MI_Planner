# DESIGN — MI_Planner UI/UX 설계 (P2B-01)

> 기준 화면: `web/design/prototype.html` (정적, 가짜 데이터). 구현 작업(P2B-02~)은 이 문서와 프로토타입을 따른다.
> 레퍼런스: Project Master(`studio/style.css`)의 톤 — 어두운 레일, 보라 포인트, 큰 제목, 카드. 값은 이 프로젝트용으로 다시 정했다.

## 1. 디자인 원칙 (판단이 갈릴 때 위에서부터 적용)
1. **Clarity (명료함)** — 화면마다 "지금 가장 중요한 한 가지"가 먼저 눈에 들어온다. 오늘 = 지금 챙길 일, 할일 = 입력창, 일지 = 오늘 칸.
2. **Deference (콘텐츠 우선)** — 크롬(사이드바·테두리·버튼)은 조용하게, 사용자가 쓴 글이 주인공. 장식 그림자·그라데이션은 로고 외 금지.
3. **Direct manipulation (바로 고친다)** — 모달 없이 인라인 편집. 체크·상태 변경은 한 번 클릭. 저장 버튼 없음(자동 저장 + "저장됨" 표시).
4. **Keyboard first** — `N` 새 할일, `/` 검색, `Esc` 편집 취소, `Enter` 확정. 모든 상호작용 요소에 포커스 링.
5. **상태를 숨기지 않는다** — 빈 상태·로딩·오류·저장 중을 모두 디자인한다. 빈 화면은 "다음에 뭘 하면 되는지"를 말한다.
6. **색은 의미일 때만** — 포인트 보라는 "선택·행동", 빨강은 "지남/높음", 노랑은 "임박", 초록은 "저장·완료". 장식용 색 금지.

- **간격**: 4px 단위(4·8·12·16·20·24·32). 카드 안 여백 20px, 카드 사이 20px, 페이지 좌우 `clamp(20px,3.2vw,48px)`.
- **글꼴**: `Segoe UI Variable Text → Segoe UI → Malgun Gothic → system-ui` (웹폰트 금지, D-17/절대규칙). 숫자는 `tabular-nums`. 자간 `-0.012em`(본문), 제목 `-0.055em`.
- **타입 스케일**: 페이지 제목 30~40px/760 · 카드 제목 15px/700 · 본문 14px · 행 제목 14.5px/560 · 메타 12px · 라벨 11~12px/650.
- **아이콘**: 인라인 SVG(`web/js/icons.js`), 1.7px 선, 18px. 이모지·아이콘 폰트 금지.
- **다크 모드**: 이번 범위 밖(사이드바만 어두움). 토큰 구조라 나중에 추가 가능 → 필요해지면 DECISIONS에 새 항목.

## 3. 컴포넌트 규칙
| 컴포넌트 | 규칙 |
|---|---|
| 버튼 | `pri`(보라, 화면당 1개) / 기본(흰색+테두리) / `quiet`(배경 없음). 높이 36px, 눌림 `scale(.97)`. |
| **칩 (다중 선택)** | 선택 시 보라 소프트 배경 + ✓ 표시. **색만으로 상태를 구분하지 않는다**. 옆에 개수(`.n`) 허용. D-12 |
| **세그먼트 (단일 선택)** | 필터가 아니라 "보기 전환"(예: 목록/보드)에만. 지금은 정의만, 사용처 생기면 적용. |
| 체크 | 둥근 원형. 완료 시 보라로 채우고 체크 마크가 스프링으로 나타남. 행 제목은 취소선+흐리게. |
| 알약(pill) | 납기: `D-1`·`D-3`(노랑), `N일 지남`(빨강), 먼 날짜는 `MM-DD`(회색). 상태/우선순위 알약은 클릭하면 순환. |
| 우선순위 | 행 왼쪽 3px 막대 (높음 빨강, 보통 노랑, 낮음 없음). 글자 없이 훑어볼 수 있게. |
| 카드 | 흰 배경, 1px `--line`, 반경 18, `--sh-1`. 제목행(15px) + 본문. 카드 안에 카드 금지. |
| 입력 | 인라인 편집은 배경 `--accent-soft` + 포커스 링. 큰 입력(빠른 추가)은 56px, 포커스 시 보라 링 4px. |
| 빈 상태 | 점선 박스 + 굵은 한 줄(무엇) + 보조 한 줄(어떻게). |
| 상단바 | sticky, 반투명 블러. 스크롤하면 하단 선이 나타남. 브레드크럼 · 검색(`/`) · 저장 상태. |

## 4. 화면 구조
**앱 셸** — 좌 레일 236px(어두움: 로고 → 오늘/할일/월간 일지 → 페이지 트리 → 로컬 상태) + 상단바 56px + 본문(최대 1180px). 레일 배지: 할일 수(회색), 지남이 있으면 빨강. 900px 이하에서는 레일이 아이콘만 남는다.

**오늘** `#/today` — 히어로: 라벨(오늘) · 큰 날짜 · 한 줄 요약(할일 N · 임박 N · **지남 N**은 빨강) · `할일 추가`(N). 본문 2열(1.55 : 1):
- 좌: *오늘 일지* 카드(체크 줄은 원형 체크, `- [ ]` 줄에 hover하면 "할일로 만들기 ↗", 이미 만든 줄은 `→ 할일 #14` 링크), *평가 진행 현황* 카드(빗금 배경 + "곧 제공", P4-08에서 채움).
- 우: *지금 챙길 것* — 납기 지남 → 임박 → 오늘 하기로 한 일 순으로 그룹, 각 줄에서 바로 체크. 1100px 이하에서는 1열.

**할일** `#/todos` — 히어로(제목 "해야 할 일 N개" + 진행/지남 요약). 바로 아래 큰 **빠른 추가창**(N 으로 포커스). 필터 카드: 상태·우선순위·납기·요청자 칩 + 검색. 목록 카드: 행 = 체크 · 제목/메타(요청자·연결) · 납기 알약 · 상태 알약 · hover 시 삭제. 제목 클릭 = 인라인 편집(Enter 저장, Esc 취소). 완료는 기본 숨김(칩 켜면 표시).

**월간 일지** `#/page/일지/YYYY/MM` — 히어로 + 도구줄(이전·다음·오늘, 주말 접기/납기 할일 표시 칩). 그리드: 열=주(주차 라벨), 행=요일. 칸은 `--canvas` 바탕 → hover 흰색, **오늘 칸**은 보라 테두리+링+날짜 원형. 이전·다음 달 날짜는 점선+흐리게. 자동 표시 납기 할일은 칸 아래 노랑(지남은 빨강) 읽기 전용 줄. 좁으면 가로 스크롤(min 1040px).

**페이지(노트/HTML)** — 같은 히어로(제목·메타) + 본문 카드. HTML 페이지의 외부 요청 경고 배지는 `warn` 알약 규칙 사용. (P2B-04, 세부는 구현 시 확정)

## 5. 상호작용 · 상태 표
| 상황 | 표시 |
|---|---|
| 로딩 | 카드 골격(회색 막대) 0.2초 지연 후 표시. 스피너 사용 안 함. |
| 저장 | 상단바 `저장 중…`(노랑 점) → `저장됨`(초록 점). 실패 시 `저장 실패 · 다시 시도`(빨강, 클릭하면 재시도). |
| 오류 | 카드 상단 `danger-soft` 띠 + 메시지(`{"error": …}`의 문자열) + 다시 시도 버튼. |
| 화면 전환 | 본문 `opacity+translateY(6px)` 280ms 한 번. |
| 완료 체크 | 원이 채워지고 제목이 흐려짐. 되돌리기는 다시 클릭(별도 토스트 없음). |
| 삭제 | 행 삭제는 `.trash` 이동(AGENTS 규칙). 토스트 "삭제됨 · 실행 취소" 5초. |

## 6. 접근성 · 호환
- 본문 대비 4.5:1 이상(`--muted`는 메타 전용, 본문에 쓰지 않음). 클릭 영역 ≥ 30px.
- 포커스 링 `outline: 2.5px #a88cf0` 모든 버튼·입력. 체크·알약 버튼에는 `aria-label`/`aria-pressed`.
- Chromium 계열(Edge·Chrome·웨일)만 보장 (D-16). `backdrop-filter`가 안 되면 불투명 배경으로 자연스럽게 대체.
- 외부 네트워크 요청 0 — 폰트·아이콘 모두 로컬/인라인.

## 7. 구현 순서 (flow)
`P2B-02` 토큰·셸·아이콘 → `P2B-03` 오늘·할일 → `P2B-04` 월간 일지·트리·페이지 헤더 → `P2B-05` 접근성·반응형 점검. 기능·API·라우팅은 바꾸지 않고 `web/` 표현층만 교체한다.
