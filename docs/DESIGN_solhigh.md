# P2B-01 · _solhigh 디자인 시안

## 구조와 연결 편집 · 최신 시안

- **구조 관리**에서는 같은 할일을 제품·유형 등 1~2개의 분류 기준으로 묶는다. 그룹 헤더에 드롭하면 그 그룹의 필드값을 할일에 반영한다. 그룹의 추가 버튼은 분류값을 미리 채운다. 사용자 정의 분류·선택지는 구조 보기, 상세 입력, 페이지 생성, 위치 규칙에서 공유한다. 선택지 삭제는 영향받는 할일 수를 먼저 보여주며, 위치 규칙이 참조하는 항목은 그 규칙을 수정한 후 삭제한다.
- **페이지 트리**는 분류와 독립적인 보관 위치다. 행 가운데에 놓으면 하위로 이동하고, 위·아래 가장자리에 놓으면 같은 부모 내 앞뒤 순서를 바꾼다. 폴더·페이지를 옮겨도 ID와 할일 연결을 유지하며 순환 이동은 거부한다.
- **위치 규칙**은 조건들을 AND로 결합한다. 위에서 첫 일치 규칙을 적용한다. 예: 유형=셋업, 제품=HBM이면 `MI 공정업무/셋업/[제품]`이 `MI 공정업무/셋업/HBM`으로 풀린다. 일치 규칙이 없을 때의 기본 경로도 편집할 수 있다. 생성 시 경로를 미리 보고 일지 하위 또는 지정 폴더로 바꿀 수 있다. 기존 페이지 위치는 자동 재계산하지 않는다.
- **일지 연결**: 계획일·납기·명시적 일지 참조로 같은 할일 ID를 찾아 날짜 칸에 표시한다. 날짜 패널의 완료 전환, 연결된 체크 줄의 제목·체크 편집, 할일 상세 수정은 같은 할일을 갱신한다. 독립적인 일지 체크 줄은 사용자가 할일로 연결할 때까지 자유 기록이다. 아래의 초기 시안에 적힌 단방향 체크 동작을 이 규칙으로 대체한다.
- **본문 편집**: 웹 단축키가 켜진 메모·일지 본문에서 Tab/Shift+Tab은 현재 줄 또는 선택 줄을 들여쓰기/내어쓰기한다. 편집기 밖에서는 포커스를 이동한다. 본문·미리보기 더블클릭은 원문을 보존하며 접고 펼친다. 붙여넣은 이미지는 비율과 본문 폭을 기준으로 표시하고 호버/포커스에서 소형·자동·32~4096px를 선택한다.
- **새 할일 페이지**: Ctrl+N을 페이지가 수신하면 생성 패널을 연다. 브라우저의 예약 동작이 우선하는 환경에서는 Alt+N 또는 화면 버튼을 사용한다.
- 이 단계의 파일 트리와 이미지 자산은 탭 메모리에서 동작한다. 본 앱에서 파일 이동을 연결할 때는 vault 경로를 검증하고 페이지 ID를 통해 링크를 유지한다.

## 사용자 피드백 반영

오늘의 할일 행은 마우스 또는 키보드 포커스로 메모를 미리 보여준다. 설정에서 기본/컴팩트 밀도와 웹 단축키를 각각 선택한다. 편집기는 목록·체크·문자 서식·제목·들여쓰기 단축키와 서식 미리보기를 제공한다.

할일 입력은 한 줄로 시작한다. 상세 입력을 열면 납기, 요청자, 제품, 유형, 에픽, 태그를 버튼으로 선택한다. 확정된 값을 같은 탭의 다음 할일에 적용한다. 할일 페이지 추가는 새 할일과 페이지를 함께 만들고, 기존 할일의 상세에서도 같은 할일에 페이지를 연결한다. 페이지 본문은 해당 할일의 메모와 공유한다.

## 1. 핵심 판단

- 오늘 화면의 첫 화면 안에 **지금 챙길 일 + 오늘 기록**을 나란히 보여준다. 납기 지연과 오늘 계획을 즉시 읽고, 일지를 쓰기 위해 페이지를 전환하지 않는다.
- 장식 차트나 임의의 설비 지표 대신 실제 예시 할일에서 계산한 수치를 쓴다. 완료율의 분모와 주간 납기의 기간을 표시한다.
- 명세의 월간 일지 방향을 유지한다. **열=주차, 행=요일**이며 주말은 토글로 펼친다. 좁은 폭에서는 표 안에서만 가로 스크롤한다.
- 다크 계측 워크스페이스의 깊이는 근검정 배경, 얇은 경계, 낮은 채도의 패널, 절제된 블루·시안으로 만든다. 일상 업무 화면에 불필요한 3D·파형을 넣지 않는다.
- 클릭할 수 있는 요소에는 실제 동작이 있다. P4 평가 현황판은 예정 상태로 명확히 구분하며 가짜 진행률을 표시하지 않는다.

## 3. 화면과 상호작용

### 오늘

- 네 개의 요약 카드: 남은 할일, 오늘 계획, 납기 지남, 전체 완료율. 선택 시 해당 필터/계획으로 이동.
- 왼쪽: 납기 우선 또는 오늘 계획, 연결된 페이지.
- 오른쪽: 오늘 기록, 이번 주 납기 중 완료, 향후 평가 현황판 안내.
- 일지 체크 줄을 완료하거나 할일로 승격할 수 있다. 승격 시 일지에 `→ 할일 #id` 연결을 남긴다.
- 일지와 할일의 체크는 서로 다른 데이터이며 자동 양방향 동기화하지 않는다. 기존 P2 동작과 같다.

### 할일

- `N`으로 빠른 추가, Enter로 생성. 새 할일은 오늘 계획에 포함된다.
- 상태·우선순위는 다중 칩, 납기·요청자는 단일 칩. 서로 다른 필터는 AND 조건이다. 상태/우선순위를 모두 해제하면 해당 조건을 적용하지 않는다.
- 제목 클릭으로 인라인 편집, Enter 확정, Esc 취소, 포커스를 벗어나면 반영.
- 체크로 완료/원래 상태 복귀. 상태 알약은 대기 → 진행 중 → 완료 → 보류 순환.
- 상세 패널에서 제목·상태·우선순위·요청자·납기·계획일·메모를 변경하고 반영한다. 취소는 원본을 보존한다.
- 삭제는 예시 데이터만 제거하며 6초 동안 실행 취소할 수 있다. 실제 vault 삭제 기능을 호출하지 않는다.
- 검색 결과 없음은 필터 초기화 액션을 제공한다.

### 월간 일지

- 이전/다음 달, 오늘 돌아오기, 주말 표시, 납기 할일 표시.
- 날짜 칸 클릭 시 옆 패널에서 편집. 날짜와 자유 텍스트를 먼저 보여주고 납기 할일은 읽기 전용 영역으로 분리한다.
- 납기 할일 자동 표시는 본문에 기록하지 않는다. 프로토타입에서는 표시 토글을 탭 메모리에만 유지한다.
- 오늘 테두리와 날짜 배지, 이번 주 헤더 강조, 월 밖 날짜 비활성.
- 주차·요일 헤더와 행/셀의 접근성 의미를 유지한다.

### 노트 / HTML

- 페이지 트리는 접기·펼치기 가능한 계층이며 노트·일지·HTML 페이지에 연결된다.
- 노트는 읽기 전용 레이아웃 시안이다. 편집 툴바처럼 보이는 비작동 버튼을 넣지 않는다.
- HTML 페이지 예시는 반복도 계산기다. 표본표준편차(n−1), 평균의 A형 표준불확도(s/√n)를 계산한다. 독립 반복 측정 가정을 표시하고 비수치·표본 수 부족·계산 범위 초과 입력을 거부한다.
- 계산기는 프로토타입 안에서만 동작한다. 실제 HTML 페이지의 sandbox/CSP/상태 브리지 교체는 범위 밖이다.

### 전체 검색과 접근성

- `/`로 할일·페이지 통합 검색. 결과에서 페이지 또는 할일 상세로 이동.
- Esc로 패널 닫기. 대화상자 안에서 Tab을 순환시키고 배경을 inert 처리하며 종료 시 포커스를 복원한다.
- 본문 건너뛰기, 입력 레이블, 상태 변경 알림, 명시적인 포커스 링, reduced-motion 대응.
- 1440/1280/1024px 데스크톱 점검. 1020px 이하에서는 레일을 아이콘으로 축소하며 760px 이하에서는 본문을 한 열로 표시한다.
- 매우 좁은 미리보기에서는 레일을 숨기고 검색으로 페이지를 이동할 수 있다. 정식 모바일 앱 지원은 추가하지 않는다.

## 4. 실행·저장 경계

- 단일 HTML을 더블클릭해 실행한다. 빌드, 서버, 설치, CDN, 폰트 다운로드가 필요 없다.
- 외부 호출을 CSP로 차단한다. `fetch`, 원격 이미지, 외부 CSS/JS를 쓰지 않는다.
- 모든 설비·Lot·요청자는 가짜 데이터다. 재현 가능한 납기 검토를 위해 예시 날짜를 **2026-11-24**로 고정했다.
- 변경은 탭 메모리에만 존재한다. localStorage/IndexedDB/파일/API 쓰기를 사용하지 않으며 새로고침하면 초기화된다. 이 사실을 푸터와 편집 패널에서 알린다.
- 실제 앱 저장·API·라우팅·DB는 수정하지 않는다. 새 의존성도 없다.

## 5. 인수인계

- `_solhigh` 시안 제작과 검증까지 수행한다. 본 앱으로의 이식은 P2B-02 이후의 별도 작업이다.
- 기존 flow의 P2B-01은 **사용자 시안 선택 후 done 처리**하는 조건을 유지한다. 이번 제작 요청만으로 기존 라이트 시안을 폐기하거나 승인 완료로 간주하지 않는다.
- 이 시안을 선택하면 `DESIGN.md`/결정 기록을 다크 토큰과 위 레이아웃으로 정합화하고 셸 → 오늘·할일 → 일지·페이지 순으로 이식한다.
- 실제 앱의 자동 저장은 기존 명세를 유지한다. 프로토타입의 명시적인 “변경 반영” 버튼은 탭 메모리 체험을 위한 경계이며 영구 저장 UX의 변경안이 아니다.
