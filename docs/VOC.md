# VOC — 사용자 의견·불편·요청함

> 사용자가 직접 쓰거나 에이전트가 대화에서 옮겨 적는다. **작업을 고를 때 flow보다 먼저 본다.**
> 처리가 끝나면 `상태`를 `완료`로 바꾸고 커밋 해시를 적는다. 지우지 않는다.

## 쓰는 법
- 한 건 = 표의 한 줄. ID는 `V-001`부터 순서대로.
- 우선순위: **P1** 쓰기 막힘·데이터 위험 / **P2** 자주 불편 / **P3** 있으면 좋음
- 상태: `대기` · `진행` · `완료` · `보류`(사유 기재)
- 영역: 화면 이름이나 flow 작업 ID(예: `P2B-05`)
