# status-brief — 설비 현황 브리핑

데이터는 `python -m app.cli`(AGENTS.md 9장)로만 읽는다. 이 스킬은 **아무것도 쓰지 않는다**.

## 언제 쓰나
- "지금 EQ-A01 뭐 해야 돼?", "EQ-A01 평가 어디까지 왔어?" → 설비 하나
- "평가 #3 정리해줘" → 평가 하나 / "오늘 뭐 남았어?" → 진행 중 평가 전체
- 표에 값을 넣는 일이면 `fill-table`, 할일을 만들거나 고치는 일이면 CLI `task` 명령을 직접 쓴다.

## 입력
- 설비 이름(일부만 써도 됨, 대소문자 무시) 또는 평가 ID. 둘 다 없으면 진행 중 평가 전체.
- 'AI에게 요청'으로 받은 위치가 평가 현황판 페이지면 그 페이지의 `_page.json`에 있는 `eval_id`를 쓴다.

## 절차
1. MI_Planner 폴더에서 모으기(한 번에 다 모은다):
   `python skills/status-brief/scripts/brief.py --equipment EQ-A01 --md`
   (평가 하나: `--eval 3`, 기한 범위: `--days 3`, 원자료가 필요하면 `--md`를 빼서 JSON으로 본다)
   - 스크립트를 못 쓰면 같은 내용을 CLI로 직접: `eval list` → 진행 중 평가마다 `eval show ID --full`에서 그 설비 칸만 → `eval stalled` → `task list --open --q EQ-A01`, `task list --overdue`, `task list --due-within 7` → `search EQ-A01`.
2. `matched_equipment`가 비면 추측하지 말고 "그 설비를 찾지 못했다"고 하고 `eval list`의 설비 이름을 보여 준다. 두 개 이상 걸리면(예: `EQ-A0` → A01·A02) 어느 쪽인지 묻거나 둘 다 따로 정리한다.
3. 우선순위를 이 순서로 매긴다:
   1) 경고 칸(`stalled`, warn 2가 1보다 먼저, 대기 시간이 긴 것 먼저) — 단계 기준 시간을 넘긴 MOS·검사 대기
   2) 기한 지난 할일
   3) 평가별로 마지막 단계가 아닌 칸 묶음 → "다음 단계"로 옮길 일(대기 시간이 긴 묶음 먼저)
   4) N일 안 기한 할일
   5) 빈 값 항목(`empty_fields`) — 결과를 아직 안 넣은 칸. 넣을 raw data가 있으면 `fill-table`을 제안
4. 참고 페이지(`notes`)는 제목만 보고 넘기지 말고, 1~3번에 관련된 페이지 1~2개는 `vault/<경로>/index.md`를 열어 최근 메모(막힌 이유, 담당자)를 한 줄로 덧붙인다.
5. 출력 형식대로 답한다. 숫자(장수·시간·기한)는 스크립트 결과 그대로 쓰고 지어내지 않는다.

## 출력
```
## EQ-A01 현황 (2026-11-24 기준)
**먼저**
1. LOT-TEST-001#02 리뷰대기 30시간(기준 24h) — 리뷰 진행 후 `분류대기`로 옮기기
2. 할일 #12 PM 후 재측정 — 기한 11-20 지남
**다음**
- 합성 평가 #3: 검사대기 4장 → 검사완료 / 분류완료 2장 → 정리완료
**이번 주 기한** · 할일 #15 결과 보고 (11-26)
**빈 값** · 스캔 시간 4칸 — raw data 있으면 fill-table로 채울 수 있음
```
- 10줄 안팎. 칸 ID·할일 ID를 남겨 두면 사용자가 바로 다음 명령을 줄 수 있다.
- 마지막에 바로 할 수 있는 명령을 1~2개 제안한다(예: "4장을 검사완료로 옮길까요?" → 승인받으면 `python -m app.cli eval set-stage 3 --cells 11,12,13,14 --stage inspection_done`).

## 하지 말 것
- 사용자 확인 없이 단계 이동·할일 수정·노트 쓰기를 하지 않는다(이 스킬은 읽기만).
- DB 파일(`data/mi_planner.db`)을 직접 열거나 SQL을 쓰지 않는다.
- 대기 시간을 직접 계산해 저장하거나 지어내지 않는다(D-09, CLI가 계산).
- RCP(레시피) 쓰기 금지(D-11). 외부 네트워크 금지. 예시는 가짜 값(`EQ-A01`, `LOT-TEST-001`)만.
